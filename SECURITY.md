# Security policy

## Supported versions
Only the latest release gets security fixes.

## Reporting a vulnerability
Please don't open a public issue for security problems, such as a way to crash the server, bypass the round rules or escape the headstart freeze.

Report it privately instead: go to the [Security tab](https://github.com/Purdze/Hounded/security) and click **Report a vulnerability**. Include the Hounded and server versions, and steps to reproduce.

You'll get a reply as soon as possible. Once a fix is released, the report can be made public, with credit to you if you like.
